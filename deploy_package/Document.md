# راهنمای جامع دیپلوی روی ابرآروان (Zero-to-Hero)

این فایل راهنمای کامل، قدم‌به‌قدم و تست‌شده برای راه‌اندازی پنل ادمین (React) و API (Spring Boot) پلتفرم **کلاسور (مثبت علم)** بر روی سرورهای ابری ایران (ابرآروان) با مشخصات محدود (۲ گیگابایت رم) است.

## ۱. آماده‌سازی سرور و اتصال
مشخصات سرور شما:
- **IP:** `37.32.23.243`
- **پسورد:** `oTLeEtoqjA`

ابتدا با استفاده از برنامه PuTTY (در ویندوز) یا ترمینال، به سرور متصل شوید:
```bash
ssh root@37.32.23.243
# پسورد: oTLeEtoqjA
```

## ۲. نصب داکر و تنظیم رجیستری ایران (دور زدن تحریم و ملی‌شدن نت)
برای اینکه داکر بتواند ایمیج‌ها را در سرورهای ایرانی بدون مشکل دانلود کند، باید از Mirror های ایرانی استفاده کنیم. دستورات زیر را خط‌به‌خط در ترمینال سرور کپی و اجرا کنید:

```bash
# نصب داکر و داکر کامپوز
apt update && apt install -y docker.io docker-compose

# ساخت پوشه تنظیمات داکر در صورت عدم وجود
mkdir -p /etc/docker

# تنظیم رجیستری‌های ایرانی برای دور زدن تحریم داکر
cat <<EOF > /etc/docker/daemon.json
{
  "registry-mirrors": [
    "https://docker.arvancloud.ir",
    "https://docker.iranserver.com"
  ]
}
EOF

# ری‌استارت سرویس داکر برای اعمال تغییرات
systemctl daemon-reload
systemctl restart docker
```

## ۳. آپلود فایل‌ها روی سرور
شما در حال حاضر یک فایل `deploy_kelasor.zip` در اختیار دارید. این فایل را از طریق برنامه‌هایی مانند **WinSCP** یا **FileZilla** روی سرور (مثلاً در مسیر `/root/`) آپلود کنید.

پس از آپلود، آن را اکسترکت کنید:
```bash
apt install -y unzip
unzip deploy_kelasor.zip -d /root/kelasor
cd /root/kelasor
```

### ساختار فایل‌هایی که اکسترکت می‌شوند:
- `docker-compose.yml`: کانفیگ اصلی سرورها.
- `Caddyfile`: وب‌سرور سبک برای مدیریت دامنه و SSL.
- پوشه `backend`: حاوی فایل اجرایی جاوا (`app.jar`).
- پوشه `frontend`: حاوی بیلد نهایی پنل ادمین (فایل‌های استاتیک HTML/JS).

## ۴. تنظیمات دامنه (DNS)
قبل از اجرای سرور، حتماً وارد پنل دامنه خود (یا پنل DNS ابرآروان) شوید و رکورد زیر را اضافه کنید:
- **Type:** `A`
- **Name/Host:** `@` (یا خالی)
- **Value/IP:** `37.32.23.243`
- تیک پروکسی ابرآروان (ابرک نارنجی) می‌تواند **روشن** یا **خاموش** باشد. (برای گرفتن گواهینامه اولیه بهتر است خاموش باشد، اما Caddy معمولاً مشکلی با آن ندارد).

## ۵. اجرای پروژه (استارت نهایی)
حالا که در پوشه `/root/kelasor` هستید، دستور زیر را برای اجرای همزمان بک‌اند، فرانت‌اند و دیتابیس بزنید:

```bash
docker-compose up -d
```

### چه اتفاقی می‌افتد؟
1. **دیتابیس:** PostgreSQL اجرا می‌شود.
2. **بک‌اند:** فایل `app.jar` با رم محدود (`-Xmx1024m`) روی کانتینر Alpine اجرا می‌شود تا به سرور فشار نیاید. دیتابیس کلاسور ساخته می‌شود.
3. **وب‌سرور (Caddy):** فایل‌های پنل ادمین را در آدرس `kelasorapp.ir` نمایش می‌دهد، درخواست‌های `kelasorapp.ir/api` را به بک‌اند می‌فرستد و **به‌طور کاملاً خودکار** گواهینامه SSL رایگان و معتبر (Let's Encrypt) دریافت می‌کند.

## ۶. بررسی وضعیت
برای اطمینان از درست اجرا شدن سرورها، لاگ‌ها را ببینید:
```bash
# لاگ‌های بک‌اند (اسپرینگ‌بوت)
docker-compose logs -f backend

# لاگ‌های وب‌سرور (Caddy) برای بررسی موفقیت‌آمیز بودن صدور SSL
docker-compose logs -f caddy
```

پایان! پنل شما با موفقیت و بالاترین سرعت ممکن روی سرور ۲ گیگابایتی اجرا شد و از طریق `https://kelasorapp.ir` در دسترس است.
